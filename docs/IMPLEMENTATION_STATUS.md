# 实施状态与验收边界

## 交互改进（2026-11-15）

多选修复：只按实际几何命中，忽略轨道的存储原点；过小手势不触发选择。圈选结束自动切回选择工具，支持整组拖动、整组删除、单事务撤销。多对象状态显示独立面板，不再误显示首个对象的属性。新增几何与浏览器整组操作回归测试，当前共 16 项核心测试、9 项浏览器测试通过。

最新调整：画笔已合并为一个工具（P，兼容 B）。统一颜色和粗细，笔迹可直接保留并随时播放；点击转换后才参与物理。旧版自由涂鸦也支持转换，不丢失颜色、粗细或撤销能力。以下独立画笔条目为此前迭代记录。

- 新增独立自由画笔（B）：颜色、粗细、任意形状及单点涂鸦可保存；不进入物理、不阻止播放。原物理画笔（P）保留转换流程。擦除支持拖动擦除涂鸦与待转换笔迹，一次拖动可整体撤销。
- 组件工具持续选中，可连续放置，按 V 切回选择。
- 弹簧使用一致的实体外壳与顶板碰撞轮廓，顶部下落接触才弹射；侧面和底部接触不触发。视觉增加线圈、顶板、底座和短暂压缩反馈。旧场景如果因新实体高度产生重叠，可使用位置修正预览或手动移动。
- 更新蓝紫色工作台、组件配色、选中状态和自由画笔设置浮层。
- 本轮：15 项核心/物理/API 测试与 7 项浏览器测试通过，类型检查和生产构建通过。此前性能报告是上一个实现版本的采样，不作为本轮改动后的性能复测。

## 有意保留的实施差异

1. 首次打开使用完整“入杯”场景，可以立即播放；缺一段轨道的渐进引导与虚线建议区尚未实现。
2. 本地圆拟合采用包围盒中心估计与径向误差；未实现高阶最小二乘拟合和置信度排序。识别失败可保留笔迹、重画、使用组件或主动请求图片识别；已识别候选可换类型、排除。
3. 多段轨道可以拖动各顶点；AI 只能修改语义对象整体，尚无单段子选择。直接“变陡 10°”只对单段轨道开放。
4. 图片理解为可配置模型路径，有裁剪、上传确认、坐标映射与结果校验，但没有真实模型测试。模型不支持图片时不开放该入口。
5. 预览中的新增候选可换类型或排除，并可请求确定性位置修正；尚无预览层直接拖动手柄。可取消后用手动工具重建，或应用后再编辑。
6. 保存场景、笔迹和恢复副本使用同一 IndexedDB 事务；笔迹没有另设 drafts store。撤销与重做只在当前会话保留。
7. 冲突保存会停用覆盖并提示导出/刷新；没有自动合并与专门的另存对话框。恢复副本全损坏时尚无损坏原件下载 UI，原记录不会被主动删除。
8. 请求额度采用固定预扣而非按 usage 结算；由部署者指定保守的成本上界并配合供应商硬限额。没有完成实际账单对照。
9. 单 Canvas 每帧重绘；尚未引入静态层缓存、显示插值或长期过载提示。先记录实测，再决定是否优化。
10. 初始重叠与边界检查、速度上限、预测接触、CCD 和异常暂停已实现；目标卡顿或路径连通性不做自动求解。

## 运行限制

只有圆是动态刚体。弹簧是一次冲量弹射器，持续停留不连续施力。模拟后编辑必须重置；不把最终落点保存为设计稿。数据仅保存在浏览器，不是云端备份。

技术基线安装版本：Node.js 24.18.0、React 19.3.1、Vite 7.3.8、TypeScript 5.9.3、Rapier 0.19.3、Zod 4.6.7、Hono 4.13.18、Vitest 4.1.12、Playwright 1.65.1；完整依赖见 package-lock.json。Rapier、React 等 API 行为以本仓库锁定版本与测试为准。
