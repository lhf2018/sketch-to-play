## 本机满容量采样

原始结果：[local.json](local.json)。复现脚本：`scripts/benchmark.mjs`。

| 条件 / 指标      | 实测                                |
| ---------------- | ----------------------------------- |
| CPU              | Intel Core i5-12400F，12 逻辑核     |
| 内存             | 约 15.9 GiB                         |

| 场景             | 80 个语义对象、30 个球、160 段轨道  |
| 持续时间         | 60 秒                               |
| 实际物理步数     | 7,199                               |
| 帧数             | 3,601                               |
| 平均帧率         | 60.01 FPS                           |
| 帧间隔 P95       | 16.8 ms                             |
| 单物理步耗时 P95 | 0.30 ms                             |
| 首次物理初始化   | 61.7 ms（本地开发服务器，非冷网络） |

采样为完整 Canvas 渲染加物理运行。使用开发构建和当前机器，场景为压力脚本构造；采样初期有其他自动测试运行，未将其剔除。该结果支持当前容量的可行性判断，**不能当作 PRD 指定参考设备、生产构建、冷缓存网络或所有复杂场景的最终性能验收**。

第一次脚本采样因恢复时序 / HMR 模块引用问题没有推进物理，已丢弃。最终脚本使用开发态测量接口获取实际控制器，并强制要求运行态且至少 7,000 个物理步，否则报错而不写成功结果。

## 物理调参记录

固定步长为 1/120 秒，CCD 开启，最大 CCD 子步为 4，求解迭代数为 8，预测接触距离为 0.08 米，最大线速度 12 m/s。默认预测接触参数在高速斜坡测试中曾出现明显瞬时穿插；调整后，固定的 100 条接近测试通过。

100 条条件覆盖不同入射位置和轨道角度，检查接触过程中的法向位置，不只检查最终落点。端点、折角与杯壁更全面的组合仍需按 PRD A11 扩充。
